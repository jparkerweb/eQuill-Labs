A recurring reminder that counts from when you started it, and then actually interrupts you rather than waiting to be noticed. It ships for Windows, macOS and Linux as one self-contained binary each, written in Go, with all of the settings documentation kept on a single docs site so two copies cannot drift. Nothing it ships is code signed, a deliberate choice rather than an oversight, so the first launch costs one extra click past SmartScreen on Windows or Privacy & Security on macOS. It contacts the network exactly once, and only when you press Check for updates in the settings window: it downloads nothing, installs nothing, and there is no background check and no telemetry of any kind. The Linux binary is built on Ubuntu 24.04 and needs glibc 2.39 or newer, with sound provided through libasound.so.2. Licensed under Apache License 2.0.
